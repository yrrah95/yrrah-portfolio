## 這是什麼
`slack-gif-creator` 是官方 `example-skills` 裡的 skill。
它用來做 Slack 表情動圖。
貼文說它不是找圖，是用程式一格一格畫。
它不附圖庫，還附 Slack 規格檢查。

## 它怎麼跑
1. 你說：說要什麼動，例如「一顆星在彈跳」，給 Slack 用。
2. 它畫：用程式一格一格畫，合成一個 GIF 存檔。
3. 它檢查：存好後，對照 Slack 規格檢查合不合格。

## 它背好的規格
- 表情動圖：128x128 最建議。
- 訊息動圖：480x480。
- 長度：表情動圖 3 秒內。
- 每秒幾格：10~30，越少檔案越小。
- 顏色數：48~128，越少檔案越小。

## 怎麼安裝
1. 打 `claude plugin marketplace add anthropics/skills`。
2. 打 `claude plugin install example-skills@anthropic-agent-skills`。
