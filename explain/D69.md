## 這是什麼
`/insights` 把你最近的對話翻過一遍，寫成一份 HTML 報告給你。
貼文問：你知道自己最常在哪裡被 Claude Code 誤會嗎？
官方文件說，它分析這台電腦上最近的 session。

## 報告裡有什麼
- 做得好的地方：你用得最順的做法。
- 哪裡常出錯：被誤會的要求、改壞的 code。
- 建議試的功能：照你的用法給建議。
- 可以挑戰的：更大一點的工作流。

出處是官方 costs 文件。

## 跑之前先知道
- 一次最多 200 個對話。太短的對話直接跳過。
- 只算這台電腦。別台和網頁版不算。
- 會用到額度：分析本身也算你的用量。
- 報告留 30 天，跟對話紀錄一起清掉。
- 報告存在 `~/.claude/usage-data/`。

## 怎麼用
1. 在 Claude Code 裡打 `/insights`。
2. 等它跑。它會把最近的對話一個個讀過。
3. 點它給的連結，用瀏覽器打開。
4. 從「建議試的功能」挑一個照做。
