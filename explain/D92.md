## 這是什麼
`brand-guidelines` 是官方的 skill。
貼文說：跟 Claude 說「照品牌規範」。
它就用 Anthropic 的 7 個顏色、2 種字型排網頁。
做網頁、簡報時，Claude 自己套上去。

## 裡面寫了什麼
- 主色 4 個：深色字、米白底、兩種灰。
- 強調色 3 個：橘、藍、綠，輪流用在色塊上。
- 標題字型：Poppins，沒裝就用 Arial。
- 內文字型：Lora，沒裝就用 Georgia。

這兩種字型沒有中文字。
中文用電腦內建的字型。

## 怎麼用
1. 輸入 `claude plugin marketplace add anthropics/skills`。
2. 輸入 `claude plugin install example-skills@anthropic-agent-skills`。
3. 對 Claude 說 `照品牌規範 把 notes.txt 做成網頁`。

## 怎麼測
同一句話，沒裝和裝了各試一次。
- 沒裝 skill：Claude 回找不到規範檔。藍底黃線是它先暫定的配色。
- 裝了 `brand-guidelines`：米白底，橘藍綠色條輪流。顏色字型都照 skill 裡寫的。
