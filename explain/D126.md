## 這是什麼

- `emilkowalski/skills` 是 Emil Kowalski 的 GitHub repo。
- 它是一組 skill，教 Claude 做網頁介面的動畫與細節。
- README 寫明：這些 skill 來自作者在 Vercel、Linear 這些公司工作多年的經驗。
- README 列出 19 個 skill。
- 2026-11-21 這個 repo 有 58,532 顆星。
- 授權是 MIT。最近一次提交是 2026-11-15。

## 怎麼裝

1. 在你的專案資料夾打開終端機。
2. 輸入 `npx skills@latest add emilkowalski/skills`。
3. 選要安裝的 skill。
4. 選 Claude Code。

- 安裝工具需要 Node.js 22.20 以上。
- skill 預設裝進目前的專案。
- 加上 `-g`，所有專案都能用。

## 它做什麼

- `animate`：從頭做一段動畫。它選速度曲線與時間長度。
- `find-animation-opportunities`：找出該加動畫的地方，排除不該加的地方。它只提建議，不改程式。
- `improve-animations`：檢查整個專案的動畫，寫出排好順序的改善計畫。它不改程式。
- `remove-animations`：找出不需要的動畫並刪掉。它只刪除，不新增動畫。
- `mobile-native`：修正網頁在手機上的問題，例如輸入框讓頁面放大。
- `break-ui`：用最糟的資料測試畫面，例如很長的名字、空的清單。
- `break-ui` 先報告壞掉的地方。你要求後它才修。
- `learn-taste`：把你在這次對話的設計糾正寫成規則。
- `ask-emil`：你描述狀況，它推薦一個 skill。

## 用之前先知道

- 5 個 skill 設了 `disable-model-invocation: true`。
- 這 5 個是 `review-animations`、`pick-ui-library`、`prototype`、`learn-taste`、`ask-emil`。
- Claude 不會自己執行這 5 個 skill。輸入斜線指令才執行，例如 `/ask-emil`。
- `animate-expo` 給 React Native 與 Expo 用。`animate` 給網頁用。
