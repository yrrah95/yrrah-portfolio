## 這是什麼

- `archify` 是一個 skill。Claude Code、Codex、Cursor、OpenCode 都能用。
- 作者是 `tt-a1i`。
- 你描述一個想法、問題或計畫，它把內容畫成互動圖表。
- 成品是一個 HTML 檔。
- GitHub 星數是 9.4 萬。授權是 Apache-2.0。
- 最近一次推送是 2026-11-06。

## 怎麼裝

1. 把這句話貼給 Claude：`Install Archify for me by reading https://raw.githubusercontent.com/tt-a1i/archify/main/llms.txt`
2. 回答 Claude 的問題：裝在全域，或只裝在目前的專案。
3. 等 Claude 跑完安裝和檢查。

在 Claude Code 裡，skill 放在 `~/.claude/skills/` 或 `.claude/skills/`。

## 它能畫什麼

- 總共有十種圖。
- 範例：系統架構、流程、時序、資料流、時間線。
- README 也列出旅遊行程和學習地圖。
- 有一位使用者把四天的城市散步行程做成一張圖。
- 不需要先有程式碼。用一句描述就能開始。

## 怎麼用

1. 用一句話描述你要畫的東西。
2. 接著說要改哪裡。範例：「Add authentication」、「Switch to the light theme」。
3. 打開 HTML 檔，用鍵盤操作圖表。

打開之後的按鍵：

- 點一個節點，再選 `Upstream` 或 `Downstream`：看哪些東西連到它，它又連到哪些東西。
- `R`：看從一個節點到另一個節點的路徑。
- `F`：切換成簡報模式。
- `S`：換樣式。`T`：換深色或淺色。
- `E`：打開匯出選單，存成圖片。

對方打開 HTML 檔不需要安裝 Archify。
