## 這是什麼
`algorithmic-art` 是官方 `example-skills` 裡的生成藝術 skill。
貼文說 Claude 寫程式畫藝術圖，每張畫都有一個號碼。
同一個號碼永遠畫出同一張。
換一個號碼就換一張。

## 它怎麼做
1. 先取名：替這種畫風取個名字，寫成一份理念檔。
2. 再畫：照理念用程式畫，做成一個網頁檔。
3. 你來調：用瀏覽器打開，自己調著看。

## 網頁裡有
- 號碼：上一個、下一個、隨機、跳到指定號碼。
- 滑桿：每幅畫自己的參數，拖了馬上變。
- 重畫：按一下重新畫一次。
- 還原：回到最開始的設定。
- 下載：一鍵存成 PNG。

## 怎麼安裝
1. 打 `claude plugin marketplace add anthropics/skills`。
2. 打 `claude plugin install example-skills@anthropic-agent-skills`。
