## 這是什麼
Claude Code 可以直接改你電腦裡的 Excel 和 Word。
不用再複製貼上。
裝一個官方 plugin，一次拿到四個技能：
1. Excel：讀整張表，加欄位，套公式，清爛資料。
2. Word：產報告，自動加目錄和頁碼，也能改現成的檔。
3. PPT：做簡報，或把舊簡報的字全部抓出來。
4. PDF：抽文字和表格，合併拆頁，填表單，把掃描檔轉成可搜尋。

原理：這四個技能，和 Claude.ai 網頁版做檔案用的是同一套。官方把它開源，給 Claude Code 用。

## 怎麼用
1. 輸入 `/plugin marketplace add anthropics/skills`。
2. 輸入 `/plugin install document-skills@anthropic-agent-skills`。
