對方還不知道有事發生

前五課都在練「他問了，你怎麼答」。這一課相反：他還沒問，你要怎麼開口。

先回想：第五課的兩條規則是什麼？

結尾 P 不准用「正在」——狀態沒有終點。換成時間＋完成式， 至少要有一個對方的動作或你的承諾。

翻面——防守型問題不要否認，踩著對方的疑慮站上去。 （提醒：翻面之後還是要收一句下一步，兩件事一起做，不是二選一。）

先解一個矛盾

上一課我抓你一個毛病：開頭先墊一句現況當緩衝。 「還沒調整完成，預計這週三交付」「目前在處理一個 bug，預計下週一完成」—— 兩題都先講現況才敢講承諾。 這一課的第一站，偏偏就是講現況。

看起來打架，其實是同一條線的兩端。差別只有一個：

是坑他已經在問你了——他腦中有這件事，你還從現況起頭，那是拖延。

是第一站他還不知道有這件事——他腦中沒有這件事，現況是唯一的入口。

所以判斷只有一句話：他知不知道有這件事？ 知道 → 用 PREP，第一句給結論。不知道 → 用這一課的 SCQA，第一句給他會點頭的現況。

醫生不會一進門就說要開刀

想這個畫面。你走進診間坐下，醫生看你一眼，第一句話是：「你要開刀。」

你的反應不會是「好」，是「等一下，什麼？我沒事啊。」 然後接下來十分鐘，醫生講什麼你都在防守——因為他跳過了你腦中還沒有的那一段。

真正的醫生會這樣走：

  • S 現況「你上次健檢是三年前，那時候都正常。」（你點頭）
  • C 變數「但這次這個數值跑到紅字了。」（你開始緊張）
  • Q 問題「所以現在是觀察，還是處理掉？」（你開始想）
  • A 答案「我建議處理掉，下個月安排。」（你聽得進去）

同樣一句「要開刀」，放在第四站你聽得進去，放在第一站你會反彈。 不是話錯了，是位置錯了。

這四站就是 SCQA。

S 站的唯一判準：他會不會點頭

S 是全場最容易寫壞的一站，因為它看起來只是「講一下背景」。它不是。 S 的工作是拿到對方第一個點頭。

他點了頭，就等於承認「本來是這樣沒錯」。有了這個共識，你講「但是⋯⋯」的時候， 他才會覺得有事發生。他沒點頭，後面三站全部白講——他還在想你講的到底是不是事實。

他不會點頭「我們的系統架構其實有一些長期的技術債。」（這是你的判斷，不是他知道的事）

他會點頭「這套對帳流程我們用了三年，一直都跑得動。」（他知道，而且同意）

檢查方式：把 S 唸出來，對方會不會回你一句「對啊」？ 不會，就重寫。 這跟第一課的「斷句測試」是同一種檢查：唸完之後，對方腦中發生了什麼。

C 站是整段的引擎

C 是「但是」。沒有 C，S 就只是閒聊；有了 C，前面那個點頭立刻變成緊張。

C 要挑對方會在意的那個變化，不是你覺得最麻煩的那個。 這件事你第三課練過——找那個變了的東西。SCQA 的 C 站就是那個東西擺對位置。

Q 站：開一個空格，不是問一個問題

這一站最容易誤解。Q 不是「丟一個問句出去」，是讓對方心裡懸著一個等答案的東西。 問號只是開空格的其中一種手段，不是唯一的。

判準：唸完這一句，對方會不會想接「然後呢？」或「所以呢？」

開了空格「所以是再找一個人來做，還是把它自動化？」（他開始想選哪個）

開了空格「錢是多了，但要接一個我沒帶過的組，我想了三天。」（然後呢？你怎麼決定的？）

把空格填了「新的審核流程會快三天左右。」（喔。然後就沒了）

把空格填了「這個月結束就不用加班了。」（這是 A，不是 Q）

下面那兩句都是在陳述事實——它們在填空格，不是在開空格。 「我想了三天」也是陳述句，但它講了一個還沒解決的難題，所以空格開著。 差別不在有沒有問號，在講完之後事情是懸著還是收掉了。

Q 開洞，A 填洞。你如果在 Q 就把洞填了，A 站就沒事做，整段變成三站。

決定已經定了，怎麼問？

常有的情況：事情已成定局（公司要換流程、舊版本就是要停支援）。 這時候還問「要不要換」是假問句——對方沒得選，問了只會顯得你在演。

做法：往下移一層。「要不要做」關掉了，但下面這幾層永遠還開著：

  • 什麼時候「所以是這個月排時間升，還是等到最後一個月？」
  • 範圍「所以手上跑到一半的那幾件，走舊的還是全部轉過來？」
  • 誰先「所以先從哪一組開始？」
  • 代價「所以升級那天要停機多久？」

這些都是真的還沒決定的事，問出來對方會真的想一下。

對家人朋友，Q 是你卡住的那個點

講故事的時候沒有決定要下，那裡的 Q 不是問對方，是講出你當時卡在哪—— 故事的形狀是：本來好好的 → 出事了 → 我那時候很掙扎 → 後來。

平鋪「升職有更多錢，但是壓力更大。」（比較完就結束了）

卡住「錢是多了，但要接一個我沒帶過的組，我想了三天。」

同樣的內容，加一句「我想了三天」，對方就會往前傾——因為他想知道你怎麼決定的。 那個懸著的半秒就是 Q。

還有一種：替對方把他心裡那句問出來。

C「最近常常半夜要加班。」

Q「你大概在想這樣還要撐多久。」

A「這個月結束就不用了，你可以先睡不用等我。」

Q 講出她的疑問，A 剛好回答它，這一段就閉合了。

什麼時候用哪一個

  • 他已經在問你用 PREP。第一句給結論，剩下三站等他點餐。
  • 他還不知道有事用 SCQA。先拿到點頭，再講但是。
  • 只是想止住自己講廢話用 BLUF。隨時可用，門檻最低。

兩個定型可以接在一起：SCQA 開場，對方追問，再用 PREP 接。 SCQA 的 A 站講完，對方問「為什麼」，你給 R；問「例如」，你給 E。 這是同一套東西的前半段跟後半段。

對家人朋友，這是講故事的形狀

SCQA 不只是商務工具。它就是故事的骨架：本來好好的 → 出事了 → 怎麼辦 → 結果。 你講一件糗事、講一個決定怎麼來的，用的都是這個形狀。

S「上禮拜那個客戶一直沒回我。」

C「結果昨天他突然打來，說要多買兩套。」

Q「我就想說是不是搞錯了。」

A「結果是他們老闆自己用了覺得不錯。」

對家人講的時候，記得翻成人——句子裡要有一個人，不要只有系統、專案、流程。 「翻成人」＝把工作翻成「誰因為我而怎樣了」。見定型卡。 沒有人的故事，家人接不下去。

排一排：把四句排成 SCQA

  • 這套報表我們每個月都是手工做，一直都來得及。
  • 但這季客戶多了一倍，上個月做到第三天才交出去。
  • 所以是再找一個人來做，還是把它自動化？
  • 我建議自動化，兩週做完，之後每個月省八小時。

情境：主管還不知道報表這件事已經吃不消了。

認一認

選項字數一致，長度不會洩漏答案。

你要跟主管說某個舊功能該砍掉了，他完全不知道有這回事。哪一句適合當 S？

同一件事要跟主管講。什麼時候該用 PREP 而不是 SCQA？

做一做：六題，不給示範

一樣不放範例答案。 四站分四行寫。分行是刻意的——看得見四站，才會發現自己漏了哪一站。 前三題工作情境，後三題家人朋友。六十秒一題，四站寫完就送出。

  • S 是對方會點頭的事，不是我的判斷
  • C 是對方會在意的那個變化
  • Q 開了一個空格（唸完對方會想接「然後呢」），不是把空格填掉
  • 如果事情已成定局：Q 有往下移一層（時間／範圍／誰先／代價），不是問假問句
  • A 有下一步，沒有出現「正在」
  • 如果對象是家人朋友：句子裡有出現一個人

你要主動跟主管提：某個每週都在做的手工流程該自動化了。他從來沒想過這件事。

你要跟一個老客戶說：他們用的舊版本三個月後不再支援了。他還不知道。

你要跟團隊成員說：這個月開始要改用新的流程。他們還沒聽說。

跟媽媽講你這個月工作上發生的一件事。她完全不知道你在忙什麼。

跟老朋友講你為什麼會決定自己開公司。他只知道你以前在上班。

跟另一半講你最近為什麼比較晚回家。她知道你晚回家，但不知道原因。

這一週的實地任務

找一次你要主動開口的場合（不是被問的），開口前先在心裡問一句：

  1. 他知不知道有這件事？不知道 → 走 SCQA
  2. 我的 S 講出去，他會不會回我一句「對啊」？
  3. 講完 A 之後閉嘴，等他追問。他問什麼，就用 PREP 的那一站接

第二步是這一課的全部。拿不到那個點頭，後面講什麼都是你一個人在講。
