## 這是什麼
`/dataviz` 是 Claude Code 內建的指令。
不用另外裝，打 `/dataviz` 就能叫。
它叫 Claude 照圖表設計規則畫圖表。
貼文說：加在最前面，圖表的標題直接寫結論。

## 怎麼用
1. 先把資料放進 `data.csv`。
2. 輸入 `/dataviz 用 data.csv 畫一張圖，存成單一 HTML 檔，不要連外部資源`。
3. 把 `data.csv` 換成你的資料檔。

## 怎麼測
同一份資料，沒加和加了 `/dataviz` 各畫一次。
- 沒加：標題是「每週各飲品銷量」，只寫主題。誰賣得好，要自己看圖。
- 加了：標題寫「週五起，拿鐵反超美式」，直接寫結論。

## 注意
- 色盤是預設的中性色。要品牌色，得自己講。
- 官方寫會跑腳本驗色盲與對比。
