## 這是什麼
CLAUDE.md 寫了一堆規則，Claude 還是不照做。
官方文件建議一份控制在 200 行內。
太長，它更不容易照做。

## 為什麼會這樣
- 它怎麼讀：開新對話時，整份讀進去。
- 當成參考：不是強制執行的設定。
- 越長越吃：占掉對話能用的空間。
- 官方說法：超過 200 行更難照做。

出處是官方 memory 文件。

## 寫法對照
含糊的寫法：
- 把程式碼排整齊。
- 改完要測試。
- 檔案要放整齊。

可驗證的寫法：
- 縮排用 2 個空格。
- 提交前先跑 npm test。
- API 放 src/api/。

## 怎麼做
1. 打開 `/memory`，列出你所有的 CLAUDE.md。
2. 選一個檔案，開編輯器看有幾行。
3. 含糊的改具體，互相矛盾的刪掉。
4. 打 `/context`，看 Memory files 有列到。
