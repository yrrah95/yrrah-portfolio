## 這是什麼

`mvanhorn/last30days-skill` 是一個 GitHub repo。
它是一個 Claude Code plugin，裡面的 skill 叫 `last30days`。
你給它一個主題，它找最近 30 天大家對這個主題說了什麼。
它找的地方有 Reddit、X、YouTube、Hacker News、Polymarket、GitHub 和一般網頁。
它照互動數、相關程度和新舊排序結果，再整理成一份摘要。
GitHub 上有 6.7 萬顆星，授權是 MIT。

## 怎麼裝

在 Claude Code 輸入這兩行：

1. `/plugin marketplace add mvanhorn/last30days-skill`
2. `/plugin install last30days`

裝好之後，輸入 `/last30days`，再加上你要查的主題。
第一次用的時候，它開一個設定精靈。
設定精靈幫你打開更多來源。

## 它做什麼

1. 它找出和主題有關的帳號、討論區和 repo。
2. 它同時搜尋所有來源。
3. 它抓 Reddit 的熱門留言和按讚數。
4. 它抓 YouTube 影片的逐字稿，再挑出關鍵句。
5. 不同平台講同一件事，它合併成一則。
6. 它寫成一份摘要。摘要裡的每一條都附上出處。
7. 摘要寫完，你可以在同一個對話裡接著問它。

## 用之前先知道

- Reddit、Hacker News、Polymarket、GitHub 不用金鑰。裝好就能查。
- X：它用你瀏覽器裡的 X 登入，或用你填的 X 金鑰。
- 它讀瀏覽器的登入資料之前，先問你。你拒絕，它就不讀。
- YouTube：要先裝 `yt-dlp`，它才抓得到逐字稿。
- Threads、Instagram、TikTok：要另外申請 ScrapeCreators 的金鑰。README 寫：前 10,000 次免費，之後照用量付費。
- 電腦要先裝好 Python 和 Node.js。
- 研究結果預設存在「文件」資料夾裡的 `Last30Days` 資料夾。
- 你設了 OpenAI、xAI 這類服務的金鑰，它把主題和抓到的內容片段送去那個服務排序。你沒設，它用本機排序。
