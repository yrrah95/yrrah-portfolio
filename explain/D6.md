## 這是什麼
`i-have-adhd` 是一個 skill。貼文說它有 7700 顆星。
它逼 Claude 講重點：沒有鋪陳、沒有客套、沒有結尾廢話。

它的規則：
1. 第一句先給下一步。
2. 多步驟就編號。
3. 結尾給一個明確的下一步。
4. 砍掉離題的內容。
5. 沒有前言、沒有回顧、沒有結尾客套。

## 怎麼用
1. 輸入 `claude plugin marketplace add ayghri/i-have-adhd`。
2. 輸入 `claude plugin install i-have-adhd@i-have-adhd`。
3. 輸入 `/i-have-adhd`。
