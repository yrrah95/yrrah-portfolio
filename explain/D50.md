## 這是什麼
`/diff` 是一個指令，用來開變更面板。
貼文說，Claude 改完一輪，你不知道它到底動了哪些檔。
你還要另開視窗敲 `git diff` 一個個對。
開了面板之後，面板貼在對話旁。
Claude 邊改，面板邊更新，動過的檔都列著。

## 面板裡怎麼看
1. 在全螢幕模式下打 `/diff` 開，再打一次關。
2. 按左右鍵，切換目前的 git diff 和 Claude 的每一輪。
3. 按上下鍵選檔，按 Enter 打開那個檔的 diff。
4. 在檔案 diff 裡按 Esc，回到檔案清單。

## 注意
- 要在 git 專案裡用，它看的是 git 的變更。
- 別的視窗切分支或 commit，面板自己刷新。
- 自訂 diff 樣式沒用，它直接讀 git 原始內容算 diff。
- 沒開全螢幕時，`/diff` 只開獨立檢視器。
