## 這是什麼
`prototype` 是 Matt Pocock 的 skill。
它出自 mattpocock/skills，總榜安裝 966K。
貼文說：它的 SKILL.md 規定 Claude 一開始就把雛形當成會丟掉的。
不寫測試，不加抽象，做完只留驗證過的決定。

## 怎麼用
1. 輸入 `npx skills add https://github.com/mattpocock/skills --skill prototype`。

SKILL.md 先把問題分成兩種，問題決定雛形的形狀：
- 問邏輯對不對：做成單一 HTML 檔，按按鈕試。非工程師也能點著玩。
- 問長什麼樣：同一頁做 3 個版本切換。版本不能只換顏色。

## 兩種都要守的規矩
- 一開始：就標明這是會丟掉的。
- 好啟動：一行指令或雙擊就能跑。
- 不存檔：狀態只放記憶體。
- 不修飾：不寫測試，不加抽象。
- 秀狀態：每次操作後印出完整狀態。

## 做完怎麼收
- 結論：收進正式程式碼。
- 雛形：放到拋棄式分支，不進主線。
- 位置：issue 裡註明分支在哪。
- 答案：記下結論和回答的問題。
- 主線：只留驗證過的決定。
