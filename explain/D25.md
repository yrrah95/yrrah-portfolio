## 這是什麼
有些事 Claude 幫不了你。
例如登入你的後台、按下申請金鑰、把那串密碼複製出來。
`wizard` 是 Matt Pocock 的 skill。
它改成幫你排隊帶路。
你說要設定什麼，它產一支腳本。

## 怎麼用
1. 腳本自己開網址，直接講點哪個按鈕、複製哪一串。
2. 你貼回來的值，它幫你寫進設定檔。
3. 密碼那種值，打字時畫面不顯示。
4. 有些值 GitHub 上也要放一份，它一起幫你存好。
5. 每一關畫面只留當下這一步。
6. 它告訴你總共幾關、現在第幾關。
7. 中途關掉沒差，下次重跑。
8. 填過的值，按 `Enter` 就跳過。

## 怎麼裝
1. 輸入 `npx skills@latest add mattpocock/skills --skill wizard`。
