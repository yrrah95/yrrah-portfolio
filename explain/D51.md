## 這是什麼
`/security-review` 是一個指令，用來做資安審查。
貼文說，資安審查以為要本科系才看得懂。
其實叫 Claude Code 做，你不會寫 code 也行。

## 怎麼用
1. 把舊檔案存成 git 變更，讓它讀得到。
2. 打 `/security-review`，它列出問題在哪。
3. 哪一行看不懂，直接問它，它會解釋。
4. 叫它把結果寫成報告，主管問了直接拿出來。

## 還能查什麼
- 沒進 git：直接貼程式碼問，一樣行。
- 看不懂：問它這行在幹嗎，它直接解釋。
- 要交差：請它寫成正式說明文。
- 審查範圍：它抓的是目前有改動的地方。

## 報告長這樣
- 抓到什麼：每個弱點跟位置。
- 多嚴重：風險等級。
- 怎麼修：建議的修法。
- 還沒解決：留著的風險。
