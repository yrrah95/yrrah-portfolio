## 這是什麼
貼文說：叫 Claude 修 bug，它東改西改，改完 bug 還在。
`diagnosing-bugs` 是 Matt Pocock 的 skill，貼文說它治這個問題。
第一條規矩：還沒做出「跑一下就知道修好沒」的檢查指令，不准動手改 code。

它的五條規矩：
1. 先建檢查指令。每改一次跑一次，修掉了沒有，立刻知道。
2. 把重現 bug 的步驟一步步刪，刪到剩最少。問題就鎖死在那幾步裡。
3. 列 3~5 個嫌疑，從最可疑的查起。不准認定第一個就是兇手。
4. debug 加的 log 全掛同一個記號。收尾搜一次，全刪光。
5. 修之前先寫自動檢查。bug 還在，它就失敗。修完它通過，才算真的修好。

## 怎麼用
輸入 `npx -y skills add mattpocock/skills --skill diagnosing-bugs --agent claude-code`。
