## 這是什麼
You should know 是 Claude Code 的內建外掛。
Claude 做長任務時，旁邊多一個 agent 盯著。
它發現你漏看的事，會在輸入框上面提醒你。
它是內建外掛，不用另外安裝。

## 提醒分兩種
- You should know：某個東西怎麼運作，跟你有關。
- Heads up：這次工作裡要小心的事。
- Heads up 包括 Claude 做的決定，和結果有誤的情況。

## 怎麼打開
1. 外掛預設是關的。要自己打開。
2. 在 Claude Code 裡打 `/plugin enable cc-plugin-you-should-know@builtin`。
3. 找不到時，到 `/plugin` 的 Installed 頁。
4. 在那一頁選 Show disabled。

## 打開之前
- 版本要 2.1.287 以上。
- 條件是 first-party 且遙測開著。
- 組織沒開放就看不到。
- 要關掉，在 `/plugin` 裡 disable 它。
