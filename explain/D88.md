## 這是什麼
`webapp-testing` 是官方 `example-skills` 裡的 skill。
它用來測你做好的網頁。
貼文說這個 skill 只教 Claude 3 步。
這 3 步是先看畫面，再找按鈕，最後才動手。
它用看不見的瀏覽器，還能截圖。

## 它怎麼測
1. 先看：打開頁面，等它載完，截圖看畫面。
2. 再找：從畫面認出有哪些按鈕和欄位。
3. 才動手：照認出來的按鈕去點、去填。

## 用的時候
- 測試腳本由 Claude 寫。
- 沒開伺服器時，附的 `with_server.py` 幫你開。
- 單純 HTML：直接讀檔，找按鈕。
- 動態網頁：要等載完才能看。
- 它還能看瀏覽器的紀錄。

## 怎麼安裝
1. 打 `claude plugin marketplace add anthropics/skills`。
2. 打 `claude plugin install example-skills@anthropic-agent-skills`。
