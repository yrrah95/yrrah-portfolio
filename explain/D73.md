## 這是什麼
Claude Code 的快捷鍵可以自己改。
貼文說只有 7 個鍵改不動。
其他的鍵都可以換成你順手的鍵。
存檔就生效，不用重開 Claude Code。

## 常改的預設鍵
- `Ctrl+J`：換行，不會把訊息送出。
- `Ctrl+G`：打開外部編輯器寫長文。
- `Ctrl+S`：把打到一半的訊息先收起來。
- `Ctrl+T`：顯示或收起待辦清單。
- 設成 `null`：把不想要的預設鍵拿掉。

## 改之前要知道
- `Ctrl+C`、`Ctrl+D` 等 7 個保留鍵改不動。
- 組合鍵是兩個鍵連按，每下要在 3 秒內。
- 動作名打錯時，那行會被跳過，原本的預設鍵照用。
- 用 `claude --debug` 打開，可以看警告，知道哪行寫錯。

## 改一個鍵
1. 在 Claude Code 裡打 `/keybindings`。
2. 或直接跟 Claude 說「把 Ctrl+E 設成開編輯器」。
3. Claude 會改 `~/.claude/keybindings.json`。
4. 存檔後馬上生效，不用重開。
