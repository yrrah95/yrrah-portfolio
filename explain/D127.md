## 這是什麼

你裝了一個 skill。Claude 沒有使用這個 skill。
Claude Code 官方文件有一份檢查清單。
這一頁照官方文件的順序寫。

## 怎麼查

1. 輸入 `/skills`。看清單裡有沒有這個 skill。
2. 問 Claude：`What skills are available?`
3. 用 skill 說明裡的字眼，再講一次你的要求。
4. 輸入斜線加 skill 的名稱，直接叫它。

## 常見原因

- 檔案沒有放進資料夾。正確位置是 `.claude/skills/名稱/SKILL.md`。
- skill 設了 `disable-model-invocation: true`。清單上標 `user-only`。Claude 不會自己使用它。
- 你講的話和 skill 的說明沒有共同字眼。
- 檔案最上面那段設定的格式錯了。斜線指令還能用，Claude 對不到說明。

## 實測

- 測試專案放三個 skill。
- `meeting-notes` 是單一個 `.md` 檔。Claude 回答清單裡沒有它。
- 把它搬成 `meeting-notes/SKILL.md`。Claude 回答清單裡有它。
- `deploy-check` 設了 `disable-model-invocation: true`。兩次都不在清單裡。
