## 這是什麼
`discernment-nudge` 是一個 skill。
貼文說，它上週上架了。
它上架在官方 skill 庫 anthropics/skills。
貼文說這個庫有 17 萬顆星。
AI 回答完，它會多附 2~3 條回問句。
回問句專挑你該懷疑的地方。

## 怎麼安裝
1. 打 `/plugin marketplace add anthropics/skills`。
2. 打 `/plugin install discernment-nudge@anthropic-agent-skills`。

## 怎麼用
1. 照平常的方式問，什麼都不用改。
2. 它先把你的問題完整答完。
3. 答案後面多出 2~3 條可以直接回貼的問題。
4. 把最戳你的那條貼回去，叫它再驗一次。

## 回問句看什麼
- 查事實：答案裡哪個數字、哪個說法要先求證。
- 問推理：哪一步是它自己假設出來的。
- 補脈絡：你沒講的背景，它先標給你看。

## 它不出手的時候
- 閒聊創作：寫故事、聊天沒什麼好查的。
- 查定義：問「X 是什麼」一查就有。
- 跑得動的 code：程式碼跑一次就知道對不對。
- 你已經叫它查：你要它附出處時，它不再疊一層。

一次對話最多只提醒一次。
