## 這是什麼

`coreyhaines31/marketingskills` 是一個 GitHub repo。
它收了 53 個 skill，也是一個 Claude Code plugin。
每個 skill 負責一種行銷工作，例如網頁轉換、文案、搜尋排名、廣告、定價。
作者是 Corey Haines。
GitHub 上有 59,861 顆星，授權是 MIT。

## 怎麼裝

在 Claude Code 輸入這兩行：

1. `/plugin marketplace add coreyhaines31/marketingskills`
2. `/plugin install marketing-skills`

README 寫：`/plugin` 只能在互動式的 Claude Code 命令列使用。
在網頁版或非互動環境，改輸入這一行：

`npx skills add coreyhaines31/marketingskills -a claude-code`

## 它做什麼

每個 skill 是一份 markdown 檔。
它告訴 Claude 一種工作要怎麼做。
裝好之後，直接說你要做什麼。
README 的三個例子：

- `Help me optimize this landing page for conversions`：用 `cro` skill。
- `Write homepage copy for my SaaS`：用 `copywriting` skill。
- `Create a 5-email welcome sequence`：用 `emails` skill。

53 個 skill 分成幾類，每類舉幾個：

- 網頁轉換：`cro`、`signup`、`onboarding`、`popups`、`paywalls`
- 文案：`copywriting`、`copy-editing`、`cold-email`、`emails`、`social`
- 搜尋排名：`seo-audit`、`ai-seo`、`schema`
- 廣告與追蹤：`ads`、`conversion-tracking`、`ab-testing`
- 定價與銷售：`pricing`、`launch`、`sales-enablement`

## 用之前先知道

- `product-marketing` 這個 skill 建一份產品說明檔，路徑是 `.agents/product-marketing.md`。README 寫：其他 skill 動手前先讀它。
- 沒有這份檔時，`cro` 改成問你問題。
- 用 plugin 安裝時，所有 skill 一次全裝進來。
- 授權是 MIT。README 寫：想怎麼用都可以。
- README 寫：這些 skill 給技術出身的行銷人和創辦人。
- 同一批 skill 也能裝進 Codex、Cursor、Windsurf。
- README 列了贊助的廠商。README 寫：贊助不影響核心 skill 的推薦。這是 repo 自己的說法。
