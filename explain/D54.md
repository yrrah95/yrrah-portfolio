## 這是什麼
skill-creator 是官方 skill，是做工具的工具。
貼文說，同一段流程說明、同一份 prompt，你是不是每天重貼一次。
把它包成一個 skill，Claude 遇到對的情境會自己叫出來。
skill-creator 一步步問你、幫你寫 `SKILL.md`、再測觸發準不準。

## 怎麼做
1. 在專案根目錄的終端機打 `claude plugin marketplace add anthropics/skills`。
2. 打 `claude plugin install example-skills@anthropic-agent-skills`。
3. 跟它說要解決什麼問題，其餘它會問。
4. 講清楚要 Claude 會做什麼、何時觸發。
5. 拿 2~3 句真實講法，測它會不會被叫出來。

貼文說，描述欄要寫得很強硬，Claude 才不會漏觸發。

## 包成 skill 之後差在哪
現在每次：
- 重貼同一段說明。
- 它有時照做有時不。
- 換 session 又要再教。

做成 skill 後：
- 講一個字就到位。
- 每次都同一套。
- 整台電腦都能用。

## 用之前先知道
- 會一次裝進 12 個示範 skill。
- 不要的，到 `/plugin` 裡關掉。
