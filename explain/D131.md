## 這是什麼

`nykooi1/vibe-wise` 是一個 Claude Code 外掛。
它讓 Claude 在寫程式之前，先問你打算怎麼做。
做法由你決定。Claude 照你同意的做法寫程式。
寫完之後，Claude 說明它改了什麼、為什麼這樣改。
作者寫明它給想一邊做一邊學的人用。

## 怎麼裝

1. 在 Claude Code 裡輸入 `/plugin marketplace add nykooi1/vibe-wise`。
2. 等第一行跑完，再輸入 `/plugin install vibe-wise@vibe-wise`。
3. 到你要做的專案資料夾，重新打開 Claude Code。
4. 輸入 `/vibe-wise:learn`。
5. 回答設定問題。它一次只問一題。選 `Use defaults` 可以跳過偏好設定。

## 它在什麼時候停下來

- 動手之前：它問你打算怎麼做，然後等你回答。
- 做法想清楚之後：它整理你的做法。你選 `Confirm and continue`，它才記下這個做法。這一步不寫程式。
- 寫程式之前：它列出要改的地方。你選 `Implement this step`，它才寫程式。
- 寫完之後：它報告改了什麼、加了哪些測試、跑了哪些檢查。報告不用你回答。

這三種停點不是每次都會出現。準備寫程式時，寫程式之前那一步也會一起確認做法。

## 怎麼調整

直接跟它說這些句子：

- `Use fewer checkpoints.`：少停幾次。
- `Use multiple-choice questions.`：改用選擇題問你。
- `Just implement this one.`：這一步不問，直接寫。
- `Pause learning.`：暫停學習模式。輸入 `/vibe-wise:learn` 接回。

要清掉學習筆記重來，輸入 `/vibe-wise:reset`。它先備份筆記，再問你一次。你的程式不會被改。

## 用之前先知道

- 要裝 Python 3。它用 Python 接回上次的學習進度。
- 舊專案也能用。它先讀你的程式，再畫一張小地圖。
- 學習筆記存在專案裡的 `.vibe-wise` 資料夾。
- 不用註冊帳號。它沒有自己的伺服器，也不收集使用資料。
- 筆記會放進 Claude 讀的內容裡。你原本的 Claude Code 資料設定照樣適用。
