## 這是什麼
`/deep-research` 是 Claude Code 內建的指令。
你問一個問題，它分頭上網查很多來源，再互相核對。
最後給你附出處的報告。
貼文說：被核對推翻的說法，不會進報告。

## 怎麼用
1. 輸入 `/deep-research`，打在最前面。
2. 接上你想查的問題。
3. 作者另外要求用繁體中文。
4. 作者要求報告只寫 8 行以內，每行 40 字以內。
5. 作者要求每行開頭標序號，不要放網址。

## 注意
- 要等：作者實測跑了 3 分多鐘。
- 吃額度：開很多 agent，用量比平常多。
- 要有搜尋：`WebSearch` 工具要能用。
- 看進度：打 `/workflows` 看每個階段。
- 它不會自己跑，你打指令才執行。

## 報告長什麼樣
作者問的是 skills 和 subagents 差在哪。
下面是它回的 8 行報告，原文沒改。
1. Skill 是可重用的指令資料夾（SKILL.md）。
2. Subagent 是獨立的工作者，有自己的 context。
3. Skill 預設在主對話內執行，佔用主 context。
4. Subagent 看不到對話歷史，只回傳最終結果。
5. Skill 漸進載入：平時只有 description 常駐。
6. Subagent 可自訂 system prompt、工具與權限。
7. 可組合：skill 可 fork，subagent 可預載 skill。
8. 重用流程選 skill；大量輸出或需限權選 subagent。

它還附了查證後的補充，講第 3、4 行的例外：
- skill 可用 `context: fork` 改成隔離執行。
- fork 型 subagent 會繼承整段對話。
- subagent 回傳的內容不一定是簡短摘要。

它說 5 項主張都過 3 票查證。
