## 這是什麼
這是一個 prompt 技巧，用在上場前排練。
貼文說，交報告、報提案，最怕上台被問到一個你沒準備的角度。
所以先在 Claude Code 裡，把那一輪提問跑過一遍。
你叫 Claude Code 扮成審你的那個人，一題一題問。
答不順的地方就是破口。

## 怎麼用
1. 把報告或提案的原文整段貼給它。
2. 加上這句：`你現在是我主管，逐題質詢這份報告，一次一題，我回完你再問下一題`
3. 講清楚他是誰、在意什麼、會從哪裡挑毛病。
4. 每一題都開口回答。答不順的先記下來。

## 跟只問好不好差在哪
只問好不好：
- 它專挑好講的。
- 聽完就忘了。
- 沒對到真的人。

指定人逐題問：
- 問到你會心虛的。
- 逼你當場答出來。
- 貼近真實會議。

## 那個人要講多細
- 身分：主管、客戶、口試委員、投資人。
- 在意點：成本、風險、時程，還是數字。
- 口氣：溫和引導，還是直接打斷追問。
- 節奏：一次一題，答完才問下一題。

答不出來的那題，就是上場前要補的洞。
