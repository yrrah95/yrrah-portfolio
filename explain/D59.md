## 這是什麼
`claude ultrareview` 是一個指令。
它在你丟出 PR 之前，先找幾個 agent 把改動審一輪。
貼文說，PR 丟出去才發現漏洞，通常太晚。

## 怎麼用
1. 選目標。審目前改動，打 `claude ultrareview`。
2. 審某個 PR，打 `claude ultrareview <PR 編號>`。它也接 PR 連結。
3. 開審。它在雲端拉幾個 agent 一起看，預設 45 分鐘內跑完。
4. 拿結果。它印出發現清單。加 `--post` 直接貼回 PR。

## 跟舊指令差在哪
- `codereview`：單一 agent，看目前改動，幾秒到位。
- `claude ultrareview`：多個 agent，雲端跑，較久，可貼 PR 留言。
