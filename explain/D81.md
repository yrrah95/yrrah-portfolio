## 這是什麼
`doc-coauthoring` 是官方 `example-skills` 裡的 skill。
它用來寫提案、規格、決策文件。
貼文說：直接叫 Claude 寫文件，它只能猜你要什麼。
這個 skill 反過來，先問你問題。
寫完還派一個沒看過對話的 Claude 來讀。

## 三個階段
1. 倒資訊：把背景全倒給它。它再問你 5~10 題補洞。
2. 逐段寫：每段先列選項。你回「留 1 4 刪 3」，它再起草。
3. 找人讀：派沒看過對話的 Claude 讀文件，回答讀者會問的題。

## 怎麼用
- 觸發：跟它說要寫提案或規格。
- 它先問你：要走這流程，還是自由寫。
- 改稿：別自己動手，跟它說改哪裡。
- 文件放在資料夾裡的一個 md 檔。

## 怎麼安裝
1. 打 `claude plugin marketplace add anthropics/skills`。
2. 打 `claude plugin install example-skills@anthropic-agent-skills`。

這個 skill 跟另外 11 個 skill 同一包。
