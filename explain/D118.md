## 這是什麼

Claude Fable 5.2 是 Anthropic 在 2026-11-09 發布的模型。
Claude Code 2.1.321 起，`fable` 指向 Fable 5.2。
它的輸出速度比 Fable 5.1 快最多 30%。

## 怎麼切過去

1. 把 Claude Code 更新到 2.1.321 以上。
2. 輸入 `/model`，選 `fable`。
3. 要更快的速度，輸入 `/fast`。
4. 要回到 Fable 5.1，輸入 `/model claude-fable-5-1`。

## 價格與額度

- 一般速度：每百萬 token 輸入 $8，輸出 $40。
- 快速模式：速度最多 2.5 倍，價格是一般速度的兩倍。
- Pro 方案與 Team 標準席位：Fable 最多用掉每週額度的 50%。
- 限時優惠：符合資格的付費方案依訂閱時間送 1～3 次 Fable 額度重置。
