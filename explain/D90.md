## 這是什麼
`--add-dir` 是 Claude Code 的旗標。
Claude 預設只讀你開啟的資料夾。
貼文說專案外面的共用文件，預設不讓它讀。
多給一個路徑，它就讀得到。

## 三種加法
- 啟動時：`claude --add-dir ../shared`
- 對話中：輸入 `/add-dir`，加上資料夾路徑。
- 固定加：寫進設定檔的 `additionalDirectories`。

## 加了之後
- 讀檔：直接讀，不用再問你。
- 改檔：照你目前的權限模式。
- `CLAUDE.md` 預設不會一起載入。
- 網路資料夾：先對應成磁碟機代號。

## 怎麼測
1. 不加旗標，打 `claude -p "讀 ../kb/r.md"`。
2. Claude 說無法讀取，因為路徑在工作目錄之外，讀取權限沒有被授予。
3. 加上旗標，再打一次 `claude -p "讀 ../kb/r.md" --add-dir ../kb`。
4. 這次 Claude 讀得到 `../kb/r.md`，內容照樣列給你。

無人值守時，沒人能按允許。
