定型卡

三個講話的骨架，一頁看完。印出來貼在螢幕旁邊。

三個定型都在做同一件事：把「結論」搬到最前面。差別只在管多長。 共同源頭是 Barbara Minto 在 1970 年代於 McKinsey 建立的金字塔原理： 主張在上，理由在下。見 barbaraminto.com。 下面三張卡用同一個情境示範，好直接比較： 你要跟主管說登入功能得延一週。

三個定型

BLUF — 只管第一句

Bottom Line Up Front。美軍的公文規範：第一句必須是結論，後面愛怎麼講隨你。

「登入功能會延到下週三。因為第三方驗證的 API 改版了。」

什麼時候用：任何時候。門檻最低，只是一把刀，切掉開頭的廢話。 練熟這一個，八成的問題就沒了。 定義見 Wikipedia: BLUF。

PREP — 管一整段回答

結論 → 理由 → 具體例 → 再講一次結論。一個完整的小盒子。

  • P 結論登入功能我想延到下週三。
  • R 理由第三方驗證的 API 上週改版，舊接法整段失效。
  • E 例子我昨天試著沿用舊寫法，十二個測試案例掛了九個。
  • P 結論所以延一週，我重接新版，下週三給你可測的版本。

什麼時候用：對方已經在問你的時候。他知道有這件事，只是要你的答案。 最後那個 P 不是廢話——它把「所以你要做什麼」講死，對方才有動作。 例句參考 LISKUL：PREP法とは？（日文，例句最實用）。

SCQA — 管開場鋪陳

現況 → 變數 → 問題 → 答案。一段引子，把對方拉進情境。

  • S 現況登入功能原本排這週五上線。（對方已知、會點頭）
  • C 變數但第三方驗證的 API 上週改版，舊接法失效了。
  • Q 問題所以是硬上，還是延？
  • A 答案延到下週三，我重接新版。

什麼時候用：對方還不知道有事發生的時候。你得先讓他同意「本來好好的」， 他才會在意「出事了」。
注意：這就是故事的骨架——本來好好的 → 出事了 → 怎麼辦 → 結果。 講糗事、講一個決定的來龍去脈，對朋友家人一樣通。 四段拆解見 ModelThinkers: Minto Pyramid & SCQA。

S 站：他會不會點頭

S 最容易寫壞，因為它看起來只是「講一下背景」。它不是。 S 的工作是拿到對方第一個點頭。唸出來他會不會回你一句「對啊」？不會就重寫。

他不會點頭「這個版本三個月後不再支援了。」（這是 C，不是 S。等於醫生一進門說要開刀）

他會點頭「你們現在用的是 2.x，用了三年了。」（他知道，而且同意）

Q 站：開一個空格，不是問一個問題

Q 不是「丟一個問句出去」，是讓對方心裡懸著一個等答案的東西。 問號只是開空格的手段之一。判準：唸完之後，對方會不會想接「然後呢？」

開了空格「所以是再找一個人，還是把它自動化？」

開了空格「錢是多了，但要接一個我沒帶過的組，我想了三天。」

把空格填了「新的審核流程會快三天左右。」（喔。然後就沒了）

Q 開洞，A 填洞。Q 就把洞填了，A 站會沒事做，整段變成三站。

決定已成定局時（公司就是要換流程、舊版本就是要停支援）：問「要不要換」是假問句， 對方沒得選。往下移一層——什麼時候、範圍、誰先、代價，這幾層永遠還開著。

往下移「所以手上跑到一半的那幾件，走舊的還是全部轉過來？」

對家人朋友：沒有決定要下，Q 是講出你當時卡在哪（「我想了三天」）， 或替對方把他心裡那句問出來（「你大概在想這樣還要撐多久」）。

選哪一個

  • 對方已經在問你 → PREP
  • 對方還不知道有事 → SCQA
  • 只是想止住自己講廢話 → BLUF（隨時可用）

追問是點餐，不是攻擊

多數時候只講 PREP 的第一站，然後對方會告訴你他要哪一站。 他點哪一站，你上哪一站——答案的位置是固定的，所以不會空白。

  • 「為什麼？」他要 R。給理由，一個。
  • 「例如？」他要 E。給那個有數字的例子。
  • 「真的嗎？」也是要 E。懷疑只能用具體的事化解，不能用更多理由。
  • 「所以呢？」他要最後那個 P。給下一步。

兩條容易犯的規矩：R 只給一個（理由越多越像藉口）； E 裡面要有數字或畫面（沒有的話，你只是把理由換句話說）。

最後那個 P：不准用「正在」

「正在測試」「正在推廣」「正在處理」——「正在」是狀態，狀態沒有終點。 對方聽完不知道要等多久、等到什麼。換成時間 ＋ 完成式。

狀態「目前正在測試。」／「我們正在推廣。」／「正在處理。」

時間＋完成「明天修完。」／「這季推到 300 套。」／「週三前給你結果。」

判準：結尾 P 至少要有一個——對方的動作，或你的承諾。 純問句兩個都沒有。

純問句「你考慮的點是什麼？」（他答完，對話就結束了）

有承諾「我下週三再跟你確認一次，你不用特別回我。」

防守型問題：翻面

對方在掂量你夠不夠格的時候——規模、資源、會不會被大公司幹掉——最容易退回空話： 「我們有我們的優勢」。空話會招來下一個追問「什麼優勢？」，等於把球丟回去還多花一句。

不要否認他的疑慮，踩著它站上去。

否認（客戶：我們規模很小）「小也用得上。」

翻面（客戶：我們規模很小）「小反而更划算。」

否認（投資人：大公司會做）「我們有我們的優勢。」

翻面（投資人：大公司會做）「他們做，我反而好賣。」

誰在聽，決定你講什麼

結論句是「對方要的那個答案」，不是「我在做的那件事」。 開口前問一句：他聽完，要拿這句話去做什麼？答案只有三種。

  • 要做決定主管、客戶。拿去裁決或往上報。給數字、選項、代價。
  • 要做事同事、協作的人。拿去動手。給下一步在哪、要注意什麼。
  • 不做任何事家人、朋友。他要的是能接話。給一個能想像、能追問的鉤子。

同一件事實（報表功能上線，公司每月省八小時人工）：

對主管「報表上線了，每個月省八小時人力。」

對同事「報表上線了，設定都寫在 README。」

對媽媽「我做的東西上線了，省掉同事的手工。」

怎麼生出鉤子：翻成人

家人那一格最難生。訣竅是把工作翻成「誰因為我而怎樣了」—— 不要講你操作的東西，講被影響的人。

東西「我是負責維護校務系統的。」

人「學校老師登記成績的那個系統，壞掉的時候他們會打電話給我。」

東西「我忙著尋找客戶。」

人「我一週見五個人，想辦法讓其中一個願意付錢。」

東西「這件案子可以交出去了。」

人「所以我這禮拜不用再加班了。」

檢查：句子裡有沒有出現一個人？（老師、客戶、同事、你自己） 沒有人的句子，家人接不下去。

四個測試

一句話講完，用這四關檢查。任何一關沒過，重講。

  • 斷句測試對方只聽這一句就走掉，他知道發生什麼事、或你要他做什麼嗎？
  • 字數測試超過十五個字，通常是把原因也塞進去了。拆出來。
  • 接話測試他聽完會想接什麼話？無話可接，那是標籤，不是結論句。
  • 主詞測試這句話的主詞是誰？要做決定的人 → 主詞是「你」；要做事的人 → 主詞是「這件事」；家人朋友 → 主詞可以是「我」。

對客戶「這週用自己開發的程式賺到第一筆錢，好感動。」（主詞是我）

對客戶「這個工具幫你省掉每個月的手工對帳。」（主詞是你）

鉤子，不是催促

鉤子是門開著，讓對方自己走進來。催促是推他進門。 同一件事實，兩種收尾：

催促「我用我的程式賺到錢了，你要不要試試？」

鉤子「上線兩週就收到第一筆，比我想的快。」

聽到催促，對方的反應是防禦（我幹嘛聽你的）。聽到鉤子，反應是好奇（怎麼做的）。 差別在你有沒有留一個問句的位子給他。講完閉嘴，數三秒。 你一補充，就把那個位子坐掉了。

開頭句型庫

卡住的時候，從這裡挑一句丟出去，逼自己先講結果。這幾個字本身沒有意義， 它們的用處是把結論從嘴裡拉出來。

「結論是，……」

「一句話講，……」

「先講重點：……」

「結果是，……」

「我建議……，因為……」

「我需要你……」

廢話開頭黑名單

這些叫「清喉嚨式開頭」——講了但沒傳達任何資訊，只是在幫自己爭取思考時間。 這個現象與它的代價，見 Animalz: BLUF — The Military Standard。 代價是：對方的注意力在你講到重點之前就掉了。

避開「那個⋯⋯就是⋯⋯我想說一下⋯⋯」

避開「事情是這樣的，」

避開「你有沒有印象我上次提過⋯⋯」

避開「我不確定這樣講對不對，」

避開「可能有點複雜，我從頭講好了。」

要爭取思考時間，改用不欠資訊的講法：「我想一下。」停兩秒，然後直接給結論。 沉默兩秒比五句廢話短，而且顯得你在想，不是在慌。

四個小坑

第一句站得住之後，剩下的錯都在用詞。這四個最常犯：

自我否定「沒有，但最近解開了一個卡三天的問題。」

直接給「解開一個卡三天的問題，用了完全不同的方法。」

「沒有，但⋯⋯」是先關門再開門。對方在「沒有」那一刻注意力就掉了。你有東西講，別先說沒有。

評價「我開了一間公司，營收不錯。」

事實「我開了一間公司，已經有客戶在付錢。」

形容詞是你的判斷，事實讓對方自己判斷。後者更可信，也不像在炫耀。

主詞漏了「開發的專案賺到第一筆收入。」

主詞在「我開發的東西賺到第一筆收入。」

對家人，他們在意的是你，不是專案。主詞省掉，句子就變成報告。

對方不懂（對爸爸）「卡了一個 bug，卡了一個禮拜。」

換成人話（對爸爸）「有個問題卡了我一個禮拜。」

同一個詞換對象就要換。對工程師朋友講 bug 是對的，對爸爸不是。
