## 這是什麼
`skillOverrides` 是 Claude Code 的設定。
它叫 Claude 當作沒有你指定的那個 skill。
那個 skill 還留在電腦裡，只是 Claude 的清單裡看不到它。

## 怎麼設
1. 打開專案裡的 `.claude/settings.json`。
2. 加上鍵 `skillOverrides`。
3. 每個 skill 寫一行，例如 `"deploy-prod": "off"`。
4. 把 `deploy-prod` 換成你要藏的 skill 名字。

## 四種設法
- 預設：`on`，名字和說明都給 Claude 看。
- 只給名字：`name-only`，說明收起來，只剩名字。
- 只留給你：`user-invocable-only`，只有你打 /名字能用。
- 全藏起來：`off`，Claude 看不到，你也用不了。

## 怎麼測
1. 加好設定。
2. 請 Claude 列出它現在看得到的專案 skill，一行一個。

作者的結果：
- 沒設：看得到四個 skill：`deploy-prod`、`meeting-notes`、`translate-doc`、`weekly-report`。
- 設了之後：`deploy-prod` 不見了。
