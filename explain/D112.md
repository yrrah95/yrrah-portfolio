## 這是什麼

`skill-creator` 是 Claude 官方 repo `anthropics/skills` 裡的 skill。
這個 repo 有 18.8 萬以上的星數。
它幫你做新的 skill，也幫你改舊的 skill 並測試它。
這一篇不介紹成品。這一篇拆開它的 `SKILL.md`，看它怎麼對 Claude 下指令。

## 怎麼裝

1. 輸入 `claude plugin marketplace add anthropics/skills`
2. 輸入 `claude plugin install example-skills@anthropic-agent-skills`

`skill-creator` 收在 `example-skills` 這個 plugin 裡。這個 plugin 一次裝進 12 個官方 skill。

## 規則一：怎麼跟你談

- 從對話撈：你剛做完一個流程，Claude 先從對話裡整理步驟。缺的部分再問你，你確認後才往下做。
- 問四件事：要它做什麼、什麼時候叫它、交出什麼格式、要不要做測試。
- 看誰在用：原文寫水電工也開始打開終端機，爸媽和阿公阿嬤也在查怎麼安裝工具。Claude 依對象選用詞。
- 專有名詞：像 `JSON` 這種詞，對方沒表現出懂，就附一句短解釋。
- 說不用測：你說不想跑測試，Claude 就不跑，陪你邊聊邊改。

## 規則二：規矩怎麼寫

- 講為什麼：說清楚這件事為什麼重要，少用硬性的命令。
- 死命令：原文寫，寫出全大寫的 `ALWAYS` 或 `NEVER` 是黃燈。看到就改成解釋理由。
- 給範本：要固定格式，就直接貼一份範本。
- 附範例：附一組輸入和輸出，讓 Claude 照著學。
- 別寫太窄：寫通用的規矩，不要綁死在幾個例子上。

## 規則三：寫完怎麼測

- 兩份一起跑：同一題，有裝 skill 跑一次，沒裝 skill 跑一次。兩份同時開始。
- 題目像真人：測試題要有檔名、工作背景，甚至錯字。
- 差一點的題：不該用到它的測試題，要挑字面很像的題目。
- 先給你看：測完先開一個網頁讓你看結果，Claude 再動手改。
- 別只修例子：只修好那幾題，這個 skill 就沒有用。
