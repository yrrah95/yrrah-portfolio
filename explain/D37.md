## 這是什麼
貼文說，你開的兩個 Claude Code 視窗，以前互相看不到。
現在 Windows 也能讓它們互相傳話。
跨電腦也行。
以前只有 Mac 和 Linux 能用。
這次補上 Windows。

## 怎麼用
1. 打 `/list-agents`，看有哪些 session。
2. 在輸入框打 `@` 加它的名字。
3. 打 `/config`，在那一排選 accept 或 hold。

## 能做什麼
- 跨電腦：家裡和公司的 session 也找得到。
- 問進度：叫那邊回報做到哪一步。
- 丟工作：把查到的東西直接傳過去。
- 不想被打擾：設 refuse 就收不到。

## 注意
- 找得到你自己帳號的 session。
- 隊友是同一個對話派的，跟這個功能不同。
- 收件有三種選擇：accept、hold、refuse。
- session 的名字在開 session 時自動取。
- `/list-agents` 的第一行會講你自己的名字。
