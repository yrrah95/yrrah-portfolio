## 這是什麼
`/usage` 把你最近 24 小時的額度拆開給你看。
它列出 skill、plugin、MCP server 各吃掉幾 %。
別名 `/cost` 和 `/stats` 是同一個畫面。

## 畫面上有什麼
- 用量拆解：skill、subagent 各佔幾 %。
- MCP 分開算：每個 server 各列一行。
- 行為標記：長 context、快取沒命中。
- Loops 明細：排程任務跑幾次、吃多少。

出處是官方 costs 文件。

## 看之前先知道
- 數字是估算，算自這台機器的紀錄。
- 別台不算。網頁版的用量不在內。
- 標記門檻：佔 10% 以上才標出來。
- Loops 明細要 `v2.1.242` 以後才有。

## 怎麼用
1. 打 `/usage`。Claude 在跑也能打。
2. 按 `d` 看 24 小時，按 `w` 看 7 天。
3. 看排名：哪個 MCP server、skill 佔最多。
4. 沒在用的 server，打 `/mcp` 關掉。
