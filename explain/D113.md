## 這是什麼

`nextlevelbuilder/ui-ux-pro-max-skill` 是一個 GitHub repo。
它是一個 skill，也是一個 Claude Code plugin。
它幫 Claude 做網頁和介面的設計。
GitHub 上有 14.7 萬顆星，授權是 MIT。

## 怎麼裝

在 Claude Code 輸入這兩行：

1. `/plugin marketplace add nextlevelbuilder/ui-ux-pro-max-skill`
2. `/plugin install ui-ux-pro-max@ui-ux-pro-max-skill`

裝好之後，要做網頁或介面時，這個 skill 會自己啟動。

## 它先做什麼

Claude 動手寫程式之前，這個 skill 先產生一套設計。
這套設計有這些項目：

- 結構：首頁要分成哪幾塊。
- 風格：從風格庫挑一個適合的。
- 配色：依產品類型配一整組顏色。
- 字型：配好標題和內文的字體組合。
- 避免：這類產品不要犯的設計錯。

## 裝之前先知道

- 電腦要有 Python 3，搜尋腳本才跑得動。
- 沒指定技術時，預設用 HTML 加 Tailwind。
- 支援 React、Vue、SwiftUI 等 22 種技術。
- 已經有的 app，可以指定一種風格來換主題。
