## 這是什麼

- `anthropics/claude-plugins-official` 是 Anthropic 的 GitHub repo。
- 它是 Claude Code 的官方外掛市集，市集名稱是 `claude-plugins-official`。
- 市集的清單寫在 `.claude-plugin/marketplace.json` 這個檔案。
- 2026-11-19 的清單有 317 個外掛。
- 其中 41 個放在 repo 的 `plugins` 資料夾，由 Anthropic 自己維護。
- 其他外掛來自工具廠商與其他作者，例如 Figma、Notion。
- Claude Code 第一次打開互動式 session 時，會自動加上這個市集。

## 怎麼裝

1. 在 Claude Code 裡輸入 `/plugin`。
2. 在 Discover 分頁打字搜尋外掛。
3. 按 Enter 打開外掛的說明。
4. 選安裝範圍，再確認安裝。

- 知道名字時，輸入 `/plugin install 外掛名@claude-plugins-official`。
- 這個指令不會馬上安裝。它先打開外掛的說明，讓你選範圍。

## 安裝範圍

- 使用者範圍：這台電腦上你所有的專案都能用。
- 專案範圍：這個專案的所有協作者都能用。
- 本機範圍：只有你，而且只在這個專案能用。
- 不想用時，打開 `/plugin` 的 Installed 分頁。
- 在 Installed 分頁可以關掉、更新或移除外掛。

## 用之前先知道

- 官方市集的外掛有 token 用量預估。
- 用完整的安裝指令打開，或從 Marketplaces 分頁打開，才看得到預估。
- 從 Discover 清單點進去，看不到預估。
- Anthropic 不控管外掛裡的 MCP server 與檔案。先確認你信任這個外掛，再安裝。
- README 寫明：別家的外掛之後會移出這份清單，清單只留 Anthropic 自己的外掛。
- 新的外掛改到 claude.ai 的目錄投稿。
