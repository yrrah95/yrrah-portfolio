## 這是什麼
`canvas-design` 是官方 `example-skills` 裡的 skill。
它用來做海報和設計圖。
貼文說 Claude 先寫 4~6 段設計理念，寫完才動筆畫。
輸出是一頁 PNG 或 PDF。

## 它怎麼跑
1. 你說：說要做海報、設計或一件作品，給個主題。
2. 它寫：替風格取名，寫 4~6 段設計理念，存成 md 檔。
3. 它畫：照理念畫成一頁 PNG 或 PDF，再修一遍。

## 用的時候
- 做不到：動畫和影片不行，只出靜態圖。
- 字多不多：它被要求字要少，以圖為主。
- 想要多頁：另外說，它會畫成一組。

## 怎麼安裝
1. 打 `claude plugin marketplace add anthropics/skills`。
2. 打 `claude plugin install example-skills@anthropic-agent-skills`。

這個 skill 跟另外 11 個 skill 同一包。
