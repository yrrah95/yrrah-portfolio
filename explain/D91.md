## 這是什麼
`--tools` 是 Claude Code 的旗標。
它限定 Claude 能用哪些工具。
貼文說：只留 `Read` 一個工具，Claude 只能看檔案，改不了。

## 怎麼用
1. 打開終端機。
2. 輸入 `claude -p "a.txt 第一行改成完成" --tools Read`。
3. 把 `a.txt` 換成你的檔案。
4. 旗標放在句子後面。

三種留法：
- 只留讀：`claude --tools Read`
- 挑著留：`claude --tools "Bash,Edit,Read"`
- 全拿掉：`claude --tools ""`

## 怎麼測
- 沒加旗標：已開自動接受改檔，`a.txt` 被改了。
- Claude 回報：第一行從「待辦清單」改成「完成」，其餘內容未動。
- 加了旗標：同樣開自動接受，`a.txt` 沒被動。
- Claude 回報：這個工作階段只提供讀取檔案的工具，沒有編輯或寫入的工具。

## 注意
- 這個旗標管不到 MCP 工具。
- 只拿掉一個工具，用 `--disallowedTools Edit`。
- `--allowedTools` 的意思是免問直接用，不是拿掉。
