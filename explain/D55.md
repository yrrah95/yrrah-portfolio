## 這是什麼
貼文說，一有整合需求就裝一個 MCP server，幾乎是反射動作。
每接一個 server，它的工具定義預設整包進 context。
Anthropic 量過，有個流程光工具定義就吃掉 15 萬 token。

## MCP 的隱藏成本
- 工具定義：預設整包載入 context，佔 token。
- 工具結果：每次結果也在 context 進出。
- 常駐連線：server 要連著，要管閒置逾時。

## 什麼時候別接 MCP
接 MCP 的情況：
- 對方沒有 CLI。
- 要 OAuth 授權。
- 要結構化查 DB。
- 要監聽外部事件。

直接跑 CLI 的情況：
- 工具本來就有 CLI，例如 `gh`、`aws`、`docker`。
- 讓 Claude 用 Bash 跑。
- 閒置時不吃 context。

## 怎麼盤點手上的 MCP
1. 打 `/mcp`，看每個 server 有幾個工具。
2. 打 `claude mcp list`，看接了哪些 server。
3. 對沒用的 server 打 `claude mcp remove`。

接之前先問：這個直接跑 CLI 行不行？
