## 這是什麼

`blader/humanizer` 是一個 GitHub repo。
它是一個 skill，也是一個 Claude Code plugin。
它把 AI 寫的文字改寫成像人寫的文字。
改寫不改變原文的意思。
GitHub 上有 6.7 萬顆星，授權是 MIT。

## 怎麼裝

在 Claude Code 輸入這兩行：

1. `/plugin marketplace add blader/humanizer`
2. `/plugin install humanizer@humanizer`

Claude Code 的版本要 2.1.142 以上。
裝好之後，輸入 `/humanizer`，再貼上要改的文字。

## 它做什麼

它照一份清單檢查文字。
清單有 26 種 AI 常見的寫法。
下面 5 種最常見，它一看到就改：

- `Not X but Y`：先否定一件事，再講另一件事。例：`It's not just a feature, it's a shift.`
- `One-line closers`：段落最後補一句短句。例：`Let that sink in.`
- `Sayings that sound deep`：聽起來很深的話。例：`At its core, what really matters is...`
- `A staged run-up`：講重點之前先鋪陳。例：`Here's the thing.`
- `Arguing with no one`：沒有人反對，卻先辯解。例：`I'm not saying X, but...`

你貼上文字時，它給你三樣東西。
第一樣是第一版改寫。
第二樣是它對第一版的短評。
第三樣是最後的版本。

## 用之前先知道

- 它保留原文講過的每一件事。
- 附上 2 到 3 段你自己寫的文字，它照你的口氣改。
- 給它檔案路徑，它只改文字。它不改程式、資料和連結。
- 它不幫你躲 AI 偵測器。README 寫：偵測器仍然標出它大部分的輸出。
- 清單來自英文維基百科的 `Signs of AI writing` 頁面。維基百科的編輯用這一頁找出 AI 產生的文字。
- README 的範例都是英文。
