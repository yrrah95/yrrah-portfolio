## 這是什麼
裝一個官方擴充，Claude Code 就能開你桌面上的 Chrome。

原理：它不是另外開一個你看不到的瀏覽器。它接管你眼前這個。
你登入過的網站，它全部進得去，不用另外串接。

你可以叫它做這些事：
1. 讀網頁跳出來的錯誤訊息，回頭改 code。
2. 在你的 Gmail、Notion、Google 文件裡直接打字。
3. 一格一格幫你填表單。
4. 把網頁上的資料抓下來，存成檔案。
5. 把整段操作錄成 GIF。

碰到登入頁或驗證碼，它會停下來，叫你自己按。

## 怎麼用
前提：Pro 以上方案。Chrome 要裝官方擴充。沒裝的話，它會跳出來帶你裝。

輸入 `claude --chrome`。
