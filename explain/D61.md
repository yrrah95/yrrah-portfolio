## 這是什麼
貼文說，你裝的 skill 有沒有被叫過，Claude Code 自己也答不出來。
`/skill-doctor` 只講有沒有裝。它沒有「這次被叫了嗎」這一欄。
Claude Code 沒有內建的呼叫歷史。
現有工具只列出裝了但沒在用的 skill。
`PreToolUse` 這個 hook 事件能抓每次呼叫。
成本是一段設定，不用寫程式。

## 怎麼接
1. 打開 `settings.json`，加一段 `hooks`。
2. 事件填 `PreToolUse`，`matcher` 填 skill 名稱。
3. 加進這段設定：`{"hooks":{"PreToolUse":[{"matcher":"skill 名稱","hooks":[{"type":"command","command":"echo 呼叫 >> skill.log"}]}]}}`
4. skill 被叫一次，你的指令就跑一次。
5. 打 `cat skill.log`，查有沒有被叫過。

## 你會抓到什麼
- `tool_name`：skill 的名字。
- `session_id`：哪個對話呼叫的。
- `tool_input`：當次傳進去的東西。
- 時間點：hook 觸發的那一刻。

這四個欄位，自己 append 進 log。
