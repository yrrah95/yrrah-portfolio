## 這是什麼
`/batch` 是 Claude Code 內建的指令。
一個改法要套到很多檔案時，打它。
它先把大改動拆成 5 到 30 份，你點頭才開始做。

## 怎麼用
1. 在 git 專案裡打開 Claude Code。
2. 輸入 `/batch`，後面接你要改的事。
3. 看它列出的計畫，同意才開始動工。

它適合能拆成獨立小塊的大改動。
範例：整個 `src/` 從 JS 改成 TS。

## 它怎麼做
1. 先調查：讀過你的程式，拆成 5 到 30 份獨立的工作。
2. 給你看：列出計畫，你同意才開始動工。
3. 分頭做：每一份派一個背景 agent，各用獨立工作區。
4. 各收尾：每份自己改、自己跑測試，再送出變更。
