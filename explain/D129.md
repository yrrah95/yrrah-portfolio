## 這是什麼

`git-guardrails-claude-code` 是 `mattpocock/skills` 這個 repo 的 skill。
這個 repo 有 33 萬以上的星數，使用 MIT 授權。
這個 skill 叫 Claude 裝一個 hook。
這個 hook 在 Claude 跑危險的 git 指令之前擋下它。
這一篇拆開它的 `SKILL.md`，看它怎麼對 Claude 下指令。

## 怎麼裝

1. 在專案資料夾打開終端機。
2. 輸入 `npx skills add https://github.com/mattpocock/skills --skill git-guardrails-claude-code`。

這個 skill 放在 repo 的 `misc` 資料夾。
`mattpocock-skills` plugin 沒有收這個 skill。
附的腳本用 `jq` 讀出 Claude 要跑的指令。

## 它擋下哪些指令

- `git push`：把改動推上網，強制覆蓋的也算。
- `git reset --hard`：丟掉還沒存進紀錄的改動。
- `git clean -f`、`git clean -fd`：刪掉沒被 git 追蹤的新檔案。
- `git branch -D`：直接刪掉分支，不管有沒有合併。
- `git checkout .`、`git restore .`：把改到一半的檔案全部還原。

## 裝的五個步驟

1. 先問你：只擋這個專案，還是所有專案。
2. 放腳本：複製附的腳本，設成可以執行。
3. 寫設定：把 hook 加進 `settings.json`。已經有設定就合併，不蓋掉。
4. 問增減：問你要多擋或少擋哪幾條。
5. 自己測：送一條假的 `git push` 給腳本。腳本要印出 `BLOCKED` 才算過。

## 擋下的那一刻

- 什麼時候查：Claude 每次要跑終端機指令之前。
- 怎麼比對：指令裡有清單上的字，就擋。
- 被擋之後：那條指令不會執行。
- Claude 看到：使用者不准它做這件事。
