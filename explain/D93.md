## 這是什麼
`--max-budget-usd` 是 Claude Code 的旗標。
它設定花費上限，金額單位是美元。
花到上限，Claude 自己停。
這個旗標只在 `claude -p` 有效。

## 怎麼用
1. 輸入 `claude -p 摘要檔 --max-budget-usd 1`。
2. 把「摘要檔」換成你要它做的事。

## 怎麼測
- 上限 0.01 美元：Claude 回 `Error: Exceeded USD budget (0.01)`。
- 5 秒就停，摘要沒給出來。
- 上限 1 美元：同一句話，上限夠就照常跑完。
- Claude 給出資料夾裡三個小檔案的摘要。

## 注意
- 平常打開來聊天用不到，只在 `-p` 有效。
- 算的是 Claude Code 自己估的金額，不是帳單。
- 到上限才停，會超過一點，要留點餘裕。
- subagent 花的錢一起算進去。
