## 這是什麼
`--append-system-prompt` 是 Claude Code 的旗標。
它在打開時臨時加一條規則。
貼文說：同一題的回答從 77 行變 3 行。
不用改 `CLAUDE.md`。

## 怎麼用
1. 輸入 `claude -p`。
2. 接上你的問題，例如 `git rebase 跟 git merge 差在哪`。
3. 接上旗標 `--append-system-prompt`。
4. 接上規則，例如 `回答一律三行以內，每行不超過 20 個字`。

原本的規矩都在，只多這一條。
長規則放進檔案，旗標後面加 `-file`。

## 怎麼測
- 沒加旗標：回答共 77 行，開頭先說差別在怎麼處理歷史紀錄。
- 加了旗標：回答只有 3 行。
- merge 保留分支歷史，多一個 merge commit。
- rebase 把 commit 接到新基底，歷史線性。
- 已 push 的共用分支勿 rebase。

## 注意
- 這條規則只管這次打開。開新對話沒加，就沒有這條。
- 少了 append 的 `--system-prompt` 是整個換掉。
- 每次都要的規則，寫進 `CLAUDE.md` 比較省事。
