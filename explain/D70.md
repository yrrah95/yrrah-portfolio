## 這是什麼
叫 Claude Code 幫你 commit。
每一筆最後都會自動多一行 Co-Authored-By 署名。
新版有一行設定，把 commit 和 PR 的署名一起關掉。

## 它預設會加什麼
- commit：最後一行 Co-Authored-By。
- 署名寫誰：你當下在用的那個模型。
- PR 說明：最後一行寫是 Claude Code 產的。
- 雲端與遠端控制：commit 還附對話連結。

出處是官方設定文件的 attribution 節。

## 以前和現在
- 以前：`commit` 設空字串，`pr` 設空字串，`sessionUrl` 關掉。
- 2.1.281 起：一行設成 `false`。三個一次關掉。效果完全一樣。

## 怎麼關掉
1. 打 `claude update`，更新到 2.1.281 以上。舊版會跳過整份設定。
2. 打開 `~/.claude/settings.json`。
3. 在大括號裡加 `"attribution": false`。
4. 叫它 commit 一次，確認最後那行署名不見了。
