## 這是什麼

`docx` 是 `anthropics/skills` 這個 repo 的 skill。
這個 repo 是 Anthropic 官方的 skill 庫。
它有 19.7 萬以上的星數。
這個 skill 規定 Claude 怎麼做 Word 檔案。
這一篇拆開它的 `SKILL.md`，看它怎麼對 Claude 下指令。

## 怎麼裝

1. 在 Claude Code 輸入 `/plugin marketplace add anthropics/skills`
2. 輸入 `/plugin install document-skills@anthropic-agent-skills`

`document-skills` 這個 plugin 有 4 個 skill。`docx` 是其中一個。

## 新做一份時

- 清單：不准直接打圓點。清單用 Word 內建的清單功能。
- 換行：不用換行符號。每一段分開寫。
- 分隔線：不准拿表格當分隔線。分隔線用段落的下框線。
- 目錄：標題用內建的標題層級。自訂的標題樣式沒設層級，就不會進目錄。
- 寫完：把檔案轉成圖，然後看這些圖。

## 改你的舊檔時

- 舊格式：`.doc` 檔要先轉成 `.docx`。
- 別人的檔：別人給的檔是不可信的檔。解開它要用安全的方式。
- 先接字：Word 把一句話切成很多小段。先把小段接回去，才找得到那句話。
- 原樣改：直接改原本的內容。不重排它的格式。
- 改完：拿原檔對照，檢查一次。

## 用追蹤修訂改時

- 每一處：每個改動都標上作者和日期。
- 漏標：檢查會列出沒有標到的改動。
- 原文說：漏標很容易發生。接受修訂後的畫面看不出漏標。
- 乾淨版：另存一份檔案，這份檔案接受全部修訂。
