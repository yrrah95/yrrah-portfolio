## 這是什麼
`autoMemoryEnabled` 是 Claude Code 的一個設定。
它控制 Claude 會不會自己寫筆記。
預設是開。
開著時，Claude 會把你的習慣寫進筆記。
新對話會讀這些筆記。

## Claude 寫哪四種筆記
- 你是誰：你的身分和做事習慣。
- 你的糾正：你糾正過、同意過的做法。
- 進行中的事：進度、期限、做過的決定。
- 去哪找資料：專案外的資料放在哪裡。

程式裡查得到的內容，Claude 不寫進筆記。

## 怎麼關掉
1. 打開專案裡的 `.claude/settings.json`。
2. 加上 `"autoMemoryEnabled": false`。
3. 要開回來，刪掉這一行，或改成 `true`。

你也可以在對話裡打 `/memory` 來切換。

## 怎麼測
1. 告訴 Claude：「請記住：我的咖啡固定點無糖燕麥拿鐵」。
2. 開一個新對話，問：「我平常咖啡怎麼點？」
3. 設定開著：Claude 回答「無糖燕麥拿鐵」。設定關掉：Claude 回答「不知道」。
