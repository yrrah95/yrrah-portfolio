## 這是什麼
agent teams 是 Claude Code 的實驗功能。
Claude 可以一次開好幾個自己。
派出去的隊友是完整的 Claude，不是用完就丟的小幫手。
隊友之間會互相挑毛病，不是各做各的。
這個功能很吃額度。
官方建議一次 3 到 5 個。

## 怎麼開
1. 打開 `settings.json`。
2. 在 `env` 加上一行 `"CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS": "1"`。

## 怎麼用
1. 開完直接用中文講「派三個隊友,一個看 UX、一個看架構、一個唱反調」。
2. 每個隊友有自己的記憶空間，互不干擾。
3. 隊友之間直接傳話，互相挑對方的毛病。
4. 按上下鍵選人，按 `Enter` 進去單獨跟它講話。
5. 你可以要求隊友先交計畫，審過才准動手。
