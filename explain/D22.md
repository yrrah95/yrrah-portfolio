## 這是什麼
Matt Pocock 那套 25 個 skill 這禮拜改版。
整包變成 Claude Code 的 plugin。
它已經在官方市集裡，不用先加來源。
他以後改了什麼會自動更新，不用自己回去拉。

## 怎麼裝
1. 輸入 `claude plugins install mattpocock-skills`。
2. 在每個專案跑一次 `/setup-matt-pocock-skills`。
3. 回答它的問題：用哪個 issue 系統、貼什麼標籤、產出的文件放哪。

## 想自己改內容
1. 輸入 `npx skills@latest add mattpocock/skills`。
2. 檔案會複製進你的專案，你可以改。
3. 這條路不會自動更新。

兩條路挑一條。
兩條都裝的話，每個 skill 會出現兩次。
