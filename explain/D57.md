## 這是什麼
`academy-guide` 是官方內建的 skill。
你問 Claude 某個功能怎麼用，它答完後有時會多推一句「這邊有教學可以看」。
它只在你真的問到「怎麼用」時出聲。
你在忙正事時，它不出聲。
教學網址是 `academy.claude.com`。

## 四條規則
- 先答完問題：推薦只是附加，不是取代。
- 只推真的貼題的：含糊就不推，沉默好過亂推。
- 不編內容：沒讀到目錄，就不編課程名字。
- 最多兩項：寧可少推，不做落落長的清單。

## 什麼時候出聲
- 會推薦：你問「怎麼用」某個功能。
- 不推薦：你在忙正事，只要做完。
- 目錄哪來：它抓 Academy 最新課表，不是背的。
- 沒有目錄時：它改指去官網，不亂猜課名。

## 怎麼裝
1. 打 `claude plugin marketplace add anthropics/skills`，加上市集。
2. 打 `claude plugin install academy-guide@anthropic-agent-skills`，裝 skill。
3. 照常問怎麼用功能。它自己會補一句。
