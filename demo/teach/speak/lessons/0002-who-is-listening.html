對方要的那個答案

同一件事，換一個人聽，結論句就換。這一課練換。

先回想：第一課的兩個測試是什麼？

斷句測試：對方只聽這一句就走掉，他知道發生什麼事、或你要他做什麼嗎？

字數測試：超過十五個字，通常是把原因也塞進去了。

想不出來很正常，這就是回想的用處——想不出來的東西，你才知道還沒真的記住。

你上次掉在哪

第一課五題，你四題到位。掉的是這題：

情境家人吃飯時問：「你最近在忙什麼？」

你的答案「寫程式 發展我的副業」

字數對、沒有廢話開頭。但媽媽聽完，腦中只有一個畫面：你坐在電腦前面。 然後她能說什麼？只能說「喔，那不要太累」。

對照你答對的那四題——每一句聽完都有下一步：

  • 「明早給你」→ 主管去排明天的事
  • 「這次先不去」→ 朋友去改訂位
  • 「錯誤會被吞掉」→ 同事點頭，理解這次改動
  • 「不然要延後兩週」→ 主管當場二選一

「寫程式」沒有下一步。它是一個活動標籤，不是結論句。

為什麼你只在這一題掉

工作場合，對方會把要什麼寫在臉上：能不能上線、要不要給資源。目標明確，你的結論句自動對準。 這也解釋了為什麼你覺得自己「有時候」講得好、「有時候」卡住—— 差別不在你的狀態，在對方要的東西明不明顯。

家人問「你最近在忙什麼」，沒有人在跟你要東西。你不知道對方要什麼， 就退回去回答「我在做什麼動作」——那是你唯一確定的東西。

所以這一課的原則只有一句：

結論句是「對方要的那個答案」，不是「我在做的那件事」。

三種聽眾，三種要的東西

開口前問自己一句：「他聽完，要拿這句話去做什麼？」答案只有三種。

  • 要做決定主管、客戶。他要拿去裁決或往上報。給他能比較、能算的東西——數字、選項、代價。
  • 要做事同事、協作的人。他要拿去動手。給他下一步在哪、要注意什麼。
  • 不做任何事家人、朋友。他不會拿去做什麼——他要的是能接話。給他一個能想像、能追問的鉤子。

第三種是你的盲點，也是最反直覺的一種。跟家人講話，資訊不是重點， 能不能繼續講下去才是重點。同一件事：

關掉對話「寫程式，發展我的副業。」

留下鉤子「我在做一個自己的產品，想做成收入。」

差別在後面那句藏了一個目標——「想做成收入」。媽媽接得上：「那有賺到嗎？」 「什麼樣的產品？」對話就活了。

這是第三個測試，加在原本兩個之後： 接話測試——他聽完，會想接什麼話？如果對方無話可接，那是標籤，不是結論句。

配一配：一件事，三個人

事實：你做的匯出報表功能這週上線了，公司每個月少掉八小時的人工作業。

  • 主管
  • 一起維護的同事
  • 媽媽
  • 報表上線了，每個月省八小時人力
  • 報表上線了，設定都寫在 README
  • 我做的東西上線了，省掉同事的手工

認一認

每題四個選項都是十五個字，長度不會洩漏答案。

主管在週會上問：「這個功能上線後有什麼影響？」他要的是什麼？

家人問：「你最近在忙什麼？」哪一句最可能讓對話繼續下去？

做一做：同一件事，換三個人

題材用你自己的副業，比虛構情境有黏性。前三題是同一個事實，只換聽眾。 第四題是第一課那道你掉的題。隔了一段時間再考一次是故意的—— 重新想比重新看有用得多。

  • 對方聽完接得上話（不是只能回「喔，加油」）
  • 講的是對方在意的東西，不是我在做的動作
  • 沒有對方不懂的專有名詞
  • 十五個字以內

事實：你副業做的東西，這週第一次有人付錢。
講給媽媽聽。她不會拿這句去做任何事。

「我自己做的東西，這週第一次有人付錢買。」

同一件事，講給工程師朋友聽。
他可能會想動手做類似的事。

「上線兩週就收到第一筆，比我想的快。」

同一件事，講給一個可能會買的陌生人聽。
他要決定的是：這東西關我什麼事。

「這個工具幫你省掉每個月的手工對帳。」

重考：家人吃飯時問「你最近在忙什麼？」
（上次你的答案是「寫程式 發展我的副業」）

「在弄一個自己的產品，想做成一份收入。」

這一週的實地任務

只做一件事，找家人或朋友：

  1. 挑一件你這週真的做過的工作上的事
  2. 開口前，先在心裡問「他聽完會想接什麼話」
  3. 講出來，然後閉嘴，數三秒
  4. 看他有沒有接話。有接＝過關。只回「喔」＝這句還是標籤

第三步的閉嘴最重要。你一緊張就補充，一補充就蓋掉了鉤子，對方也就沒空接。 沉默是留給對方的位子。
