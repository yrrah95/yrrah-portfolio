## 這是什麼

`pptx` 是 `anthropics/skills` 這個 repo 的 skill。
這個 repo 是 Anthropic 官方的 skill 庫。
它有 20.1 萬以上的星數。
這個 skill 規定 Claude 怎麼做簡報檔。
這一篇拆開它的 `SKILL.md`，看它怎麼對 Claude 下指令。

## 怎麼裝

1. 在 Claude Code 輸入 `/plugin marketplace add anthropics/skills`
2. 輸入 `/plugin install document-skills@anthropic-agent-skills`

`document-skills` 這個 plugin 有 4 個 skill。`pptx` 是其中一個。

## 內容怎麼排

- 一張一件事：一張投影片只講一件事。一個主題講完，再換下一個主題。
- 順序：重點放在最前面。最後一段給下一步要做的事。
- 看場合：現場講的簡報，字要少。會前自己讀的簡報，內容要寫完整。
- 抓時間：現場講的簡報，一張大約講 1.5 到 2 分鐘。

## 畫面不准這樣

- 標題底線：標題底下不准加裝飾線。原文說這種線是 AI 做的簡報的標誌。
- 裝飾色條：投影片邊上不准加裝飾色條。原文說這種色條看起來像湊版面。
- 只有文字：每張投影片都要有圖片、圖示、圖表或形狀。
- 內文置中：段落和清單靠左。只有標題可以置中。
- 預設藍色：顏色照主題挑選。不要一律用藍色。

## 做完要檢查

- 轉成圖：把每一張投影片轉成圖片，然後逐張看。
- 先查爆字：第一個查字有沒有超出框，或被框切掉。
- 斷行：數字和單位被拆成兩行，也算錯誤。
- 換人看：盯著程式看久了，只會看到自己預期的畫面。原文建議交給 subagent 看圖。
- 改完：只重看改過的那幾張投影片，然後停止。
