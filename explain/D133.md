## 這是什麼

`wondelai/skills` 是一組 skill，共 66 個。
其中 52 個是方法。這些方法來自暢銷書和業界指南。
另外 14 個是帶路的 skill。它們一步一步帶你完成一件大事，例如從零做一個網站。
README 的表格列出這些方法出自哪裡。
這組 skill 分成 10 包外掛。你只裝要用的那幾包。

## 怎麼裝

1. 在 Claude Code 裡輸入 `/plugin marketplace add wondelai/skills`。
2. 輸入 `/plugin install product-strategy@wondelai-skills`。
3. 要其他包，把 `product-strategy` 換成那一包的名字，再輸入一次。
4. 裝好之後，輸入 `/` 加上「包名:skill 名」叫它，例如 `/product-strategy:mom-test`。

## 打這些指令就能用

- `/product-strategy:mom-test`：準備訪談客人。它要你問客人過去怎麼做，不問客人會不會買。
- `/product-strategy:negotiation`：準備談判。例如談加薪、談合約、價格談不攏。
- `/sales-influence:made-to-stick`：改簡報和標語，讓人聽一次就記住。
- `/ux-design:ux-heuristics`：檢查網頁好不好用。它把問題照嚴重程度排列。

這 4 個 skill 都先給目前的分數，再說哪裡要改。

## 從零做網站：帶路的 skill

`/metaskills:create-website` 從空白頁做到網站上線，共 10 個階段。

- 順序固定：先寫文案，再做設計，最後審查。最後一關審查不能跳過。
- 每個決定前，它先問你。它附上選項和它的建議。你選了，它才往下做。
- 它把決定和進度寫進專案的 `docs` 資料夾。下次打開，它從上次停的地方接著做。
- 網站上的限量、好評、保證，都要是真的。
- 要用的 skill 沒裝時，它先問你要不要裝。你不裝，它改用內建的精簡做法。
