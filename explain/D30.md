## 這是什麼
你開兩個 Claude 改同一個專案。
它們改同一個檔案時，後面那個直接蓋掉前面那個。
叫它開一個隔離的工作區，就能避開這件事。

## 怎麼用
1. 輸入 `claude --worktree 名字`。
2. 它用 git 在專案底下另外開一份完整的檔案複本，配一條新分支。
3. 想再開一份，換個名字再跑一次。兩份完全獨立。
4. 派出去的 agent 也能一人一份。在它的設定檔加一行 `isolation: worktree`。
5. 你的 `.env` 不會跟過去。在專案根目錄放一個 `.worktreeinclude`，把要帶的檔名寫進去。

## 注意
- 待在複本裡時，它去改主目錄的檔案會被擋下來。
- 它連跑指令都要留在複本裡。
