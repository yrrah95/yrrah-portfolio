## 這是什麼

`obsidianmd/obsidian-skills` 是一個 GitHub repo。
它是 Obsidian 官方出的 Claude Code plugin。
Obsidian 是一個筆記軟體。
筆記是你電腦裡的 Markdown 檔，放在一個資料夾裡。這個資料夾叫筆記庫。
這個 plugin 叫 `obsidian`，裡面有 7 個 skill。
它教 Claude 照 Obsidian 的格式寫筆記，也教 Claude 用 Obsidian 的命令列介面操作筆記庫。
GitHub 上有 5.3 萬顆星，授權是 MIT。

## 怎麼裝

在 Claude Code 輸入這兩行：

1. `/plugin marketplace add obsidianmd/obsidian-skills`
2. `/plugin install obsidian@obsidian-skills`

裝好之後，在你的筆記庫資料夾打開 Claude Code。
之後要拿到新的 skill，在終端機輸入 `claude plugin update obsidian@obsidian-skills`。

## 它做什麼

- `obsidian-markdown`：寫 Obsidian 格式的筆記。格式包含筆記之間的連結（`[[筆記名稱]]`）、嵌入、提示框（`> [!note]`）和屬性。
- `obsidian-bases`：寫 `.base` 檔。這個檔把筆記排成表格、卡片、清單、地圖或看板。你可以篩選要顯示哪些筆記。
- `json-canvas`：寫 `.canvas` 白板檔。例如心智圖和流程圖。
- `obsidian-cli`：用 Obsidian 的命令列介面讀、新增、搜尋、改名和搬移筆記。
- `defuddle`：把網頁轉成乾淨的 Markdown。它拿掉選單、廣告和其他雜訊。
- `obsidian-headless`：不開桌面版，從命令列跑 Obsidian Sync 和 Obsidian Publish。
- `knap`：用範本和 JSON、CSV 資料產生 Markdown 筆記。

## 用之前先知道

- 寫筆記、`.base` 檔和 `.canvas` 檔是直接寫檔案。這幾件事不用開著 Obsidian。
- `obsidian-cli` 要先打開 Obsidian 的命令列介面。
- 打開的步驟：在 Obsidian 進「Settings → General」，打開「Command line interface」，再照提示登記。
- 命令列介面要 Obsidian 1.12.7 以上的安裝版。
- 命令列介面要 Obsidian 正在執行。Obsidian 沒開，第一個指令會打開它。
- 你有好幾個筆記庫，又沒說要改哪一個，它改檔之前先問你。
- `defuddle` 要另外裝 Defuddle。沒裝的時候，它說明缺什麼，再問你要不要裝。
- `obsidian-headless` 要 Node.js 22 以上。Sync 和 Publish 各要有效的訂閱。
