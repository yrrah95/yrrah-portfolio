## 這是什麼
貼文說：你裝的 skill 和 MCP，在你開口之前就已經在吃額度。
貼文說：裝越多，Claude 越容易忘記你前面交代過的事，打開也越慢。

原理：每個 MCP、每個 skill 都要先把自己的說明塞進去。
Claude 才知道有這些工具可以用。
所以你還沒開口，記憶空間就先被佔掉一塊。

有一個開關可以一次全關。貼文說：跑起來正常，就代表是設定的問題。

## 怎麼用
輸入 `claude --safe-mode`。

會被關掉的：
1. `CLAUDE.md` 不讀。
2. 所有 skill、plugin 不載入。
3. hooks 不觸發。
4. MCP 不連。
5. 自訂指令、主題、快捷鍵全部停用。

還是正常的：登入、模型、內建工具、權限，跟平常一樣。
