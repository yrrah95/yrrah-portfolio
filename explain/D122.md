## 這是什麼

`xlsx` 是 `anthropics/skills` 這個 repo 的 skill。
這個 repo 是 Anthropic 官方的 skill 庫，有 19.6 萬以上的星數。
這個 skill 規定 Claude 怎麼做 Excel 檔案。
這一篇拆開它的 `SKILL.md`，看它怎麼對 Claude 下指令。

## 怎麼裝

1. 輸入 `claude plugin marketplace add anthropics/skills`
2. 輸入 `claude plugin install document-skills@anthropic-agent-skills`

`document-skills` 這個 plugin 有 4 個 skill。`xlsx` 是其中一個。

## 每份都要守的

- 公式：寫公式，不填算好的數字。輸入的數字改了，表格要跟著重算。
- 零錯誤：檢查出公式錯誤，就不准交件。
- 照你說的：工作表名稱、欄位標題、你指定的公式，一字不改。
- 數字來源：手填的數字，都在旁邊註明來源。
- 字型：整份用 Arial 這類正式字型。

## 沒報錯不等於算對

- 原文說：檢查過關，只代表公式算得出來，不代表公式是對的。
- 例子：範圍差一格，檔案沒有錯誤，數字卻是錯的。
- 也算：公式抓到別列的格子，也不報錯。
- 先做：先寫兩三條公式，核對它們抓到的數字。
- 再做：數字對了，才鋪開整張表。

## 改你的舊檔時

- 照原樣：原檔的習慣，蓋過這個 skill 的規則。
- 先找：找出原檔留給人填的格子。這些格子有不同的字色或底色。
- 只寫那裡：原本的公式，一個都不碰。
- 舊的錯：說錯誤本來就有，要打開原檔來證明。

## 財務表的顏色

- 藍字：手動填的數字。
- 黑字：公式算出來的。
- 綠字：從別的工作表抓來的。
- 紅字：從別的檔案抓來的。
- 黃底：重要的預估數字，還有要你填的格子。

你另外交代，或原檔已有別的做法，就不用這套顏色。
