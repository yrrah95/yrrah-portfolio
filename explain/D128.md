## 這是什麼

- `haydenschmitty/floorplan` 是一個 Claude Code 外掛。
- Claude 讀你的專案，畫出一張可以點的地圖。
- 地圖上每個部分、檔案、網址都有白話名字和一行說明。
- README 寫明：它是給「用 AI 做 app、但不讀程式碼的人」用的。
- 2026-11-23 這個 repo 有 6,330 顆星。
- 授權是 MIT。最近一次提交是 2026-11-16。

## 怎麼裝

1. 在終端機輸入 `claude plugin marketplace add haydenschmitty/floorplan`。
2. 輸入 `claude plugin install floorplan@floorplan`。
3. 開一個新對話。外掛在對話開始時才載入。
4. 在你的專案資料夾輸入 `/floorplan:floorplan`。

- 你需要 Node.js 18 以上。
- 它用你現有的 Claude 方案。它不需要 API key。

## 地圖上的按鈕

- `Health`：列出問題，例如寫在程式裡的金鑰、不用登入就能改資料的網址。
- 每個問題有 `Fix with Claude` 按鈕。這個按鈕複製一段修正用的提示詞。
- `Recent work`：Claude 剛改過的地方標成綠色，每一塊附一段說明。
- `Screens`：選一個頁面，看它背後連到哪些程式和資料。
- `Export`：把地圖存成一個 HTML 檔。對方不用安裝任何東西就能打開。

## 用之前先知道

- 它只寫一個 `floorplan/` 資料夾。這個資料夾不進 git。
- 你同意的話，它在 `CLAUDE.local.md` 加一小段說明。這個檔也不進 git。
- 它不改你的程式碼，也不改你的 `CLAUDE.md`。
- 作者寫明：`Health` 是快速的自動檢查，不是完整的資安審查。
