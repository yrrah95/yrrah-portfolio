## 這是什麼
`/verify` 是 Claude Code 內建的指令。
不用另外裝。
它叫 Claude 把你的 app 建置起來，真的跑一次。
交給你的是跑出來的結果，不是測試通過的報告。

## 怎麼用
1. 改完程式碼。
2. 輸入 `/verify`，打在最前面。

三個指令一組：
- `/run`：啟動你的 app，讓你看到改動真的在動。
- `/verify`：建置、執行、觀察結果，不只靠測試。
- `/run-skill-generator`：把啟動方法存成專案 skill。

## 跟只靠測試差在哪
- 測試與型別檢查：看程式碼對不對。
- 它們沒有真的打開 app，也沒看改動有沒有生效。
- `/verify`：先建置你的 app，真的執行它，看執行出來的結果。

## 怎麼知道怎麼啟動
- 不用設定：它從專案類型和 README 推測怎麼啟動。
- 會不準：要資料庫、環境檔、多步建置時。
- 食譜放在 `.claude/skills/run-名稱/`。
- 沒有食譜時，`/verify` 自己記下做法。
