## 這是什麼

- `claude-hud` 是 Claude Code 的外掛。
- 作者是 `jarrodwatts`。
- 它把狀態列放在輸入框下面，一直顯示。
- GitHub 星數是 2.9 萬。授權是 MIT。
- 最近一次推送是 2026-11-02。

## 它顯示什麼

預設有兩行：

- 第 1 行：模型、專案資料夾、git 分支。
- 第 2 行：對話用量（`context`）和訂閱的用量上限。

對話用量是一條色條。用量愈高，顏色從綠變黃，再變紅。
用量上限那一格會顯示多久後重置。

可以另外加三種行：

- 正在跑的工具
- 正在跑的子代理
- 待辦進度

## 怎麼裝

先確認兩件事：

- Claude Code 是 v2.1.260 以上。
- Node.js 是 22.18 以上。

照順序輸入：

1. `/plugin marketplace add jarrodwatts/claude-hud`
2. `/plugin install claude-hud`
3. `/reload-plugins`
4. `/hud`

`/hud` 會先問你。你同意之後，它才把狀態列指向 HUD。
Node.js 版本太舊時，`/hud` 會找本機有沒有新版，或協助你安裝。

## 想改怎麼辦

- 輸入 `/hud`，說你想要什麼。
- 範例：要顯示工具動態、要改用精簡版面、狀態列是空白的。
- Claude 先給你預覽。你同意之後才存檔。
- `/hud` 也能還原上一次的修改。
- 設定檔在 `~/.claude/plugins/claude-hud/config.json`。
- 只想關一次：用 `CLAUDE_HUD_DISABLE=1` 啟動 Claude Code。

## 更新

- Claude Code 預設不會自動更新第三方外掛。
- 想自動更新：輸入 `/plugin`，打開 Marketplaces，選 `claude-hud`，選 Enable auto-update。
